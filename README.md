# ChosuTab Neo

時計、検索、ショートカット。元のChosuTabのデザインを引き継いだ、新しいタブ拡張です。背景・検索バー・右下の時計と日付・下部のショートカットの見た目を維持しています。

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、この `ChosuTab_Neo` フォルダーを選びます。
4. 新しいタブを開きます。新しいタブの変更を確認する表示が出た場合は、変更を維持してください。
5. ツールバーの拡張機能メニューから、ChosuTab Neoを固定すると設定を開きやすくなります。

既存のChosuTabとは別の拡張です。両方が新しいタブを置き換えるため、Neoを使う際はChromeの拡張機能管理画面で既存ChosuTabを一時的にオフにしてください。既存ChosuTabのファイルや設定は変更しません。

## 使い方

- **時計・日付**：PCのローカル時刻を表示します。秒は常に表示します。タブが非表示の間は時計の更新を止め、表示に戻ると現在時刻に更新します。
- **検索**：上部中央の検索バーから検索します。初期設定はGoogleです。HTTP(S)のURLや `example.com` のようなドメインを入力すると、そのページへ移動します。元のChosuTabと同じGoogleサジェスト（最大3件）と検索履歴の候補に対応します。入力が200ms止まってから通信し、日本語変換中は抑制します。矢印キーで候補を選択し、Enterで検索、↖で検索欄へ挿入できます。履歴はローカルに最大20件保存します。
- **ショートカット**：横一列で表示し、入り切らない場合は横スクロールできます。「＋」で追加します。各項目にマウスを重ねるかキーボードでフォーカスし、表示される「…」から名前・URLを編集、または削除できます。右クリック・長押しでも編集できます。URLはHTTP(S)に対応し、省略した場合は `https://` を補います。すべて削除すると追加ボタンだけになります。変更は開いている他のNeoタブにも反映されます。
- **設定**：ツールバーのNeoアイコンで小さなPopupを開きます。
- **検索エンジン**：Google・Bing・DuckDuckGo・Yahoo! JAPANを選べます。
- **テーマ**：元のウィジェットの色と透明度を変更できます。
- **フォント**：Yomogi・Mushin（無心）の2種類から選べます。どちらもローカルに同梱し、外部フォント配信は使用しません。
- **背景**：PNG・JPEG・WebP・AVIF・GIF・BMP画像に対応します（入力10MB以下）。長辺1920px以下のWebPに変換して保存します。GIFなどのアニメーション画像は静止画になります。変換後2MBを超える画像は保存せず、エラーを表示します。「背景をリセット」で元のChosuTabと同じ背景画像に戻ります。

設定は自動保存です。Popupの「保存しました」を確認してから閉じてください。画像変換中・保存中はPopupを閉じずにお待ちください。

## インポート・エクスポート・リセット

Popupの「設定の管理」を開くと、3つの操作を使えます。普段は折りたたんでおけます。

- **エクスポート**：`ChosuTab-Neo-backup.json` をダウンロードします。背景画像、テーマカラー、透明度、フォント、検索エンジン、ショートカット、検索履歴を含みます。
- **インポート**：NeoまたはChosuTab EditからエクスポートしたJSONを選択します（10MB以下）。形式・バージョン・設定値・ショートカットURLを検証し、確認後に現在の設定を置き換えます。ファイルに含まれない設定は既定値になります。不正なファイルや保存失敗時は既存設定を維持します。
- **リセット**：確認後、背景・ショートカット・検索履歴を含むすべてのNeo設定を初期状態に戻します。

変更は開いているNeoタブにも反映されます。画像処理中や保存中は管理操作を一時的に無効にします。ChosuTab Editは、`format: "ChosuTab_ExportFile"` / `format_version: 1`（数値）の形式に対応します。形式情報のない旧JSON（v1.6.1以前の設定直書き）は拒否します。`widgetColor`はNeoのテーマカラーへ、文字列の透明度は数値へ変換し、IDのないショートカットにはIDを付与します。旧形式のnullは初期値として扱います。

Neoにないメモ・音楽・表示切り替えなどの設定は引き継ぎません。旧フォントのけいふぉんと・標準フォント系はYomogiに置き換えます。対応する形式情報があるファイルは、Neoの項目を含まない場合も読み込めますが、その場合はNeo側の設定が初期値になります。旧形式の空のショートカット一覧は、旧ChosuTabの動作に合わせて初期ショートカットになります（Neo形式の空一覧はそのまま保持）。

## 保存と権限

設定は `chrome.storage.local` に保存し、Chromeを閉じても維持されます。同じフォルダーの拡張機能を再読み込みした場合も保持されます。アンインストールすると設定は失われます。他端末への同期や既存ChosuTabからの自動移行は行いません。

設定保存には `storage` 権限を使用します。Googleサジェストのため `https://suggestqueries.google.com/*` へのアクセス権限を使用します。ショートカットのアイコンは元のChosuTabと同じGoogle faviconサービスから取得します。入力した検索語は候補取得のためGoogleへ送られ、ショートカットのドメインはアイコン取得のためGoogleへ送られます。

バックグラウンド処理・外部フレームワーク・外部フォント配信は使いません。背景画像はブラウザー内で処理し、アップロードしません。履歴はPopupの「検索履歴を削除」で削除できます。

## 開発

Manifest V3、HTML、CSS、Vanilla JavaScriptで実装しています。ビルド工程や実行時のパッケージ依存はありません。

```text
manifest.json          拡張機能の定義
newtab.html            新しいタブ
popup.html             小さな設定画面
css/newtab.css         レスポンシブなタブ画面
css/popup.css          Popupの表示
js/shared.js           既定値・検証・保存・検索URL
js/newtab.js           時計・検索・ショートカット
js/popup.js            設定・背景画像の軽量化
js/search.js           サジェストと検索履歴候補
fonts/                 Yomogi・Mushin
img/                   元のデフォルト背景
icons/                 元のChosuTabのアイコン
tests/settings.test.cjs 設定と検索の回帰テスト
```

Node.js 18以降があれば、外部パッケージなしでテストできます。

```sh
node --test tests/settings.test.cjs
node --check js/shared.js
node --check js/newtab.js
node --check js/popup.js
node --check js/search.js
```

Chrome上で、新規タブ・ショートカットの追加/編集/削除・検索・背景の変更/リセット・テーマ変更を確認してください。その後、Chromeを閉じて開き直し、同じ設定が表示されることを確認できます。

## 更新

ファイル更新後、`chrome://extensions` でNeoの再読み込みボタンを押してから、新しいタブを開きます。
